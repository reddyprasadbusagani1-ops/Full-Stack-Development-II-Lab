# Contributing Guidelines

1. Never commit directly to `main`. Create a branch: `feature/<short-name>` or `fix/<short-name>`.
2. Link every branch to a GitHub Issue; mention `Closes #<number>` in the Pull Request.
3. Write clear commit messages in the present tense, e.g. `Add login form validation`.
4. Open a Pull Request and request a review. At least **one teammate** must approve before merging.
5. Pull the latest `main` before you start work each day: `git pull origin main`.
6. Never commit `node_modules`, `.env`, passwords, tokens, or API keys.
7. Be respectful in reviews: comment on the code, not the person.
